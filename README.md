# Amazon Product Rating Prediction using Random Forest Classification

## Project Overview
This project focuses on predicting Amazon product ratings using Machine Learning. A Random Forest Classification algorithm is used to classify product ratings based on available product and review information.

## Objective
- Analyze Amazon product review data.
- Clean and preprocess the dataset.
- Apply Random Forest Classification.
- Predict product ratings.
- Evaluate model performance.

## Dataset
- Dataset: Amazon Product Reviews
- Original records: 1,597
- Records after removing missing target ratings: 1,177
- Original columns: 27
- Target variable: `reviews.rating`
- Rating classes: 1 to 5

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Import required libraries.
2. Load the dataset.
3. Explore the dataset.
4. Handle missing values.
5. Separate features and target variable.
6. Encode categorical data.
7. Split the dataset into training and testing sets.
8. Train the Random Forest Classification model.
9. Make predictions.
10. Evaluate model performance.
11. Visualize feature importance.

## Machine Learning Algorithm
**Random Forest Classifier**

The model uses 100 decision trees to predict product ratings.

## Model Performance
- Algorithm: Random Forest Classification
- Training/testing split: 80% / 20%
- Accuracy: 67.37%

Additional evaluation includes a confusion matrix, classification report, and feature importance visualization.

## Conclusion
This project demonstrates how Random Forest Classification can be applied to Amazon product review data to predict product ratings. The model achieved an initial accuracy of 67.37%.
